# История версий

## v1.1.1

_2026/10/05_

- `Исправление` Предупреждения чтения SDK XML v4 с AGP 9.1 и ошибочный запуск проверки выравнивания нативных библиотек APK при сборке модульных тестов JVM, устраненные общими плагинами сборки 1.8.3
- `Улучшение` Подняты compileSdk и targetSdk до 37 (Android 17); поведение плагина не зависит от нового целевого уровня
- `Улучшение` Значки в сведениях о приложении Android используют изображения и светлый и тёмный фон Icon Studio, сохраняя прозрачные изображения центра плагинов и существующие варианты значков лаунчера

## v1.1.0

_2026/09/13_

- `Функция` Локальная история выпусков в интерфейсе с переводами и английским запасным вариантом
- `Улучшение` Проверка полной настройки подписи, ожидаемого набора APK и воспроизводимости документации

## v1.0.1

_2026/09/11_

- `Исправление` Исправлена ошибка, из-за которой хост не мог привязаться к службе плагина после включения в центре плагинов; теперь действие «Проверить файл» доступно сразу после включения
- `Улучшение` Название и описание плагина упрощены, чтобы пользовательская документация читалась естественнее
- `Улучшение` Проверка сборки отклоняет непреднамеренные нативные зависимости и создает отчет JSON

## v1.0.0

_2026/08/02_

- `Подсказка` Первый публичный выпуск; требуется AutoJs6 с кодом версии 5268 или новее
- `Функция` Добавлено действие «Проверить файл» (только чтение) в меню файлов файлового менеджера AutoJs6 для обычных файлов любого типа (ID плагина `file-inspector`, ID действия `inspect-file`)
- `Функция` Одно последовательное чтение вычисляет вместе контрольные суммы CRC32, MD5, SHA-1, SHA-256, SHA-512, с живым прогрессом, отменой и повтором
- `Функция` Проверка целостности по вставленной ожидаемой сумме: алгоритм определяется по длине или по префиксам вроде `sha256:`, принимаются запись отпечатков `AB:CD:EF` и префикс `0x` для CRC32, сравнение выполняется за постоянное время для значений равной длины
- `Функция` Отчёт показывает имя файла, MIME-тип, расширение, заявленный и фактический размеры, снимок первых 64 байт в виде hex + ASCII и обнаружение UTF BOM
- `Функция` Распознавание 10 распространённых форматов по сигнатурным байтам в начале файла: ZIP, GZIP, PDF, PNG, JPEG, GIF87a, GIF89a, ELF, DEX, SQLite 3
- `Функция` Каждую сумму можно скопировать отдельно, весь отчёт — скопировать или отправить через системную панель; MD5 и SHA-1 несут значок Legacy
- `Функция` Плагин не запрашивает разрешений на хранилище и сеть и читает файлы только через временный content-URI только для чтения, выданный хостом; лимит 8 TiB на файл
- `Функция` В комплекте тексты интерфейса, инструкции, README и CHANGELOG на 10 языках: упрощённый китайский, традиционный китайский (Гонконг), традиционный китайский (Тайвань), английский, французский, испанский, японский, корейский, русский и арабский
- `Зависимость` Добавлена AndroidX Lifecycle ViewModel 2.9.4
