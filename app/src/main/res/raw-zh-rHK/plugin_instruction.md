檔案檢查器用於檢查 AutoJs6 檔案管理器中的任意檔案. 它只把檔案讀取一遍, 就算出 CRC32, MD5, SHA-1, SHA-256 等七種校驗和, 並顯示檔案的格式, 大小與檔案標頭. 貼上發佈方公佈的校驗碼即可核對檔案是否完整. 檢查全程唯讀, 不修改原檔案.

### 開始使用

1. 在 AutoJs6 的 "插件中心" 中確認本插件已啓用.
2. 開啟 AutoJs6 的檔案管理器, 找到要檢查的檔案.
3. 在檔案選單中選擇 "檢查檔案" (AutoJs6 6.8.1 或更高版本中位於一級選單 "File Inspector" 之下).
4. 讀取完成後, 在報告中查看 "檔案資訊", "校驗和" 與 "檔案標頭".

### 主要功能

- **校驗和**: 讀取一遍即同時算出 CRC32, MD5, SHA-1, SHA-224, SHA-256, SHA-384 與 SHA-512; MD5 與 SHA-1 標示 "舊版", 不宜作為安全證明.
- **完整性驗證**: 把發佈方公佈的校驗碼貼上到 "預期校驗碼" 並點按 "驗證", 綠色表示相符, 紅色表示不相符; 亦接受 `sha256sum` 輸出的整行.
- **檔案資訊**: 顯示偵測到的格式, 副檔名與 MIME 類型, 並估計內容是文字還是二進制; ZIP 檔案還會提示是否為 APK, JAR 或 Office 文件.
- **檔案標頭**: 以十六進制與 ASCII 對照顯示檔案的前 64 位元組, 並偵測 UTF-8, UTF-16 與 UTF-32 的位元組順序記號 (BOM).
- **大小核對**: 同時顯示宣告大小與實際大小; 檔案在讀取期間被改動時會報錯, 方便發現下載不完整或正在寫入的檔案.
- **複製與分享**: 每個校驗和與檔案標頭都可以單獨複製; 在 "報告格式" 中選擇 Markdown 或 JSON 後, 可用 "複製報告" 或 "分享" 傳送完整報告, 不建立檔案.
- **讀取進度**: 讀取大型檔案時顯示進度, 速度與剩餘時間, 可隨時 "取消"; 失敗後可點按 "重試".

### 運行要求

- Android 7.0 或更高版本.
- AutoJs6 6.8.0 或更高版本.
- 不需要儲存空間與網絡權限; 插件只讀取在檔案管理器中選中的那個檔案.

### 常見問題

**驗證結果不相符時的處理**

先確認貼上的校驗碼來自這個檔案的發佈頁面. 仍不相符時, 表示檔案與發佈方的原檔不同, 可能下載不完整或曾被改動, 請從官方渠道重新下載後再檢查.

**校驗碼相符的含義**

相符只表示檔案與公佈校驗碼的那份檔案內容一致; 檔案是否可信取決於校驗碼的來源. 請優先使用官方渠道透過 HTTPS 公佈的 SHA-256 或 SHA-512.

**貼上整行時出現檔案名稱警告的原因**

貼上 `sha256sum` 等工具輸出的整行時, 插件會比對行中的檔案名稱. 它與目前的檔案名稱不同時會顯示警告, 提醒確認貼上的是不是這個檔案的校驗碼.

**部分檔案無法檢查的原因**

常見原因有: 檔案超過 8 TiB, 檔案在讀取時被其他應用程式改動, 或檔案管理器授予的讀取權限已失效. 錯誤提示會說明具體原因, 點按 "重試" 可再次檢查.
