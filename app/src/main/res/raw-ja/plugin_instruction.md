# ファイルインスペクター

ファイルインスペクターは1回のストリーミング読み取りでファイルを検査します. CRC32, MD5, SHA-1, SHA-256, SHA-512 のチェックサムを計算し, 一般的なファイルシグネチャを識別して, 基本メタデータを報告します.

MD5 と SHA-1 はレガシーアルゴリズムとして表示されます. 期待するチェックサムを貼り付けて検証できます. 個別のチェックサムをコピーしたり, 完全な検査レポートをコピーまたは共有したりできます.

このプラグインには AutoJs6 build 5268+ が必要です. 完全に JVM 上で実装されており, デバイス ABI に依存しません.

安全性とプライバシーの制限:

- 8 TiB を超えるファイルは拒否されます.
- ファイル内容は1度だけ開かれ, 読み取り専用モードで順番に処理されます.
- 先頭の64バイトのみがファイルヘッダーとして検査されます.
- このプラグインはネットワークにアクセスせず, ストレージ権限を要求しません.
