File Inspector は AutoJs6 のファイルマネージャーにある任意のファイルを検査します. ファイルを一度読み取るだけで CRC32, MD5, SHA-1, SHA-256 など 7 種類のチェックサムを計算し, ファイルの形式, サイズ, ヘッダーを表示します. 配布元が公開したチェックサムを貼り付ければ, ファイルが完全かどうかを確認できます. 検査は読み取りのみで, 元のファイルは変更しません.

### はじめに

1. AutoJs6 の "プラグインセンター" で本プラグインが有効になっていることを確認します.
2. AutoJs6 のファイルマネージャーを開き, 検査したいファイルを探します.
3. ファイルメニューから "ファイルを検査" を選びます (AutoJs6 6.8.1 以降では最上位メニュー "File Inspector" の中にあります).
4. 読み取りが終わったら, レポートの "ファイル情報", "チェックサム", "ファイルヘッダー" を確認します.

### 主な機能

- **チェックサム**: 一度の読み取りで CRC32, MD5, SHA-1, SHA-224, SHA-256, SHA-384, SHA-512 をまとめて計算します. MD5 と SHA-1 には "レガシー" が付き, 安全性の証明には向きません.
- **完全性チェック**: 公開されたチェックサムを入力欄 "チェックサム" に貼り付けて "検証" をタップすると, 一致は緑, 不一致は赤で表示されます. `sha256sum` の出力行をそのまま貼り付けることもできます.
- **ファイル情報**: 検出された形式, 拡張子, MIME タイプを表示し, 内容がテキストかバイナリかを推定します. ZIP ファイルでは APK, JAR, Office 文書かどうかも示します.
- **ファイルヘッダー**: ファイル先頭の 64 バイトを 16 進数と ASCII で並べて表示し, UTF-8, UTF-16, UTF-32 のバイトオーダーマーク (BOM) を検出します.
- **サイズの照合**: 申告サイズと実サイズを並べて表示します. 読み取り中にファイルが変わるとエラーになるため, ダウンロードが不完全なファイルや書き込み中のファイルに気付けます.
- **コピーと共有**: チェックサムやファイルヘッダーを個別にコピーできます. "レポート形式" で Markdown か JSON を選び, "レポートをコピー" または "共有" でレポート全体を送れます. ファイルは作成しません.
- **読み取りの進行状況**: 大きなファイルでは進行状況, 速度, 残り時間を表示し, いつでも "キャンセル" できます. 失敗したときは "再試行" をタップします.

### 動作要件

- Android 7.0 以降.
- AutoJs6 6.8.0 以降.
- ストレージとネットワークの権限は不要です. プラグインはファイルマネージャーで選んだファイルだけを読み取ります.

### よくある質問

**チェックサムが一致しないときの対処**

まず, 貼り付けたチェックサムがこのファイルの配布ページのものか確認します. それでも一致しない場合, ファイルは配布元の原本と異なり, ダウンロードが不完全か改変されている可能性があります. 公式の配布元から再度ダウンロードして検査してください.

**一致したことの意味**

一致は, チェックサムが公開された元のファイルと内容が同じことを示すだけです. ファイルを信頼できるかどうかはチェックサムの入手元によります. 公式の配布元が HTTPS で公開している SHA-256 か SHA-512 を優先して使ってください.

**行全体を貼り付けたときにファイル名の警告が出る理由**

`sha256sum` などのツールの出力行を貼り付けると, プラグインは行内のファイル名を照合します. 現在のファイル名と異なる場合は警告を表示し, このファイルのチェックサムかどうかを確認するよう促します.

**一部のファイルを検査できない理由**

よくある原因は, ファイルが 8 TiB を超えている, 読み取り中に他のアプリがファイルを変更した, ファイルマネージャーから与えられた読み取り権限が失効した, のいずれかです. エラーメッセージに原因が表示されます. "再試行" をタップすると再度検査します.

詳しくは [プロジェクトページ](https://github.com/SuperMonster003/AutoJs6-Plugin-File-Inspector) をご覧ください.
