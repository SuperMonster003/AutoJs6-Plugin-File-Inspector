文件检查器用于检查 AutoJs6 文件管理器中的任意文件. 它只把文件读取一遍, 就算出 CRC32, MD5, SHA-1, SHA-256 等七种校验和, 并显示文件的格式, 大小与文件头. 粘贴发布方公布的校验和即可核对文件是否完整. 检查全程只读, 不修改原文件.

### 开始使用

1. 在 AutoJs6 的 "插件中心" 中确认本插件已启用.
2. 打开 AutoJs6 的文件管理器, 找到要检查的文件.
3. 在文件菜单中选择 "检查文件" (AutoJs6 6.8.1 及以上版本中位于一级菜单 "File Inspector" 之下).
4. 读取完成后, 在报告中查看 "文件信息", "校验和" 与 "文件头".

### 主要功能

- **校验和**: 读取一遍即同时算出 CRC32, MD5, SHA-1, SHA-224, SHA-256, SHA-384 与 SHA-512; MD5 与 SHA-1 标注 "旧版", 不宜作为安全证明.
- **完整性校验**: 把发布方公布的校验和粘贴到 "预期校验和" 并点按 "校验", 绿色表示匹配, 红色表示不匹配; 也接受 `sha256sum` 输出的整行.
- **文件信息**: 显示检测到的格式, 扩展名与 MIME 类型, 并估计内容是文本还是二进制; ZIP 文件还会提示是否为 APK, JAR 或 Office 文档.
- **文件头**: 以十六进制与 ASCII 对照显示文件的前 64 字节, 并检测 UTF-8, UTF-16 与 UTF-32 的字节顺序标记 (BOM).
- **大小核对**: 同时显示声明大小与实际大小; 文件在读取期间被改动时会报错, 便于发现下载不完整或正在写入的文件.
- **复制与分享**: 每个校验和与文件头都可以单独复制; 在 "报告格式" 中选择 Markdown 或 JSON 后, 可用 "复制报告" 或 "分享" 发送完整报告, 不创建文件.
- **读取进度**: 读取大文件时显示进度, 速度与剩余时间, 可随时 "取消"; 失败后可点按 "重试".

### 运行要求

- Android 7.0 或更高版本.
- AutoJs6 6.8.0 或更高版本.
- 不需要存储与网络权限; 插件只读取在文件管理器中选中的那个文件.

### 常见问题

**校验结果不匹配时的处理**

先确认粘贴的校验和来自这个文件的发布页面. 仍不匹配时, 说明文件与发布方的原件不同, 可能下载不完整或被改动过, 请从官方渠道重新下载后再检查.

**校验和匹配的含义**

匹配只说明文件与公布校验和的那份文件内容一致; 文件是否可信取决于校验和的来源. 请优先使用官方渠道通过 HTTPS 公布的 SHA-256 或 SHA-512.

**粘贴整行时出现文件名警告的原因**

粘贴 `sha256sum` 等工具输出的整行时, 插件会比对行中的文件名. 它与当前文件名不同时会显示警告, 提醒确认粘贴的是不是这个文件的校验和.

**部分文件无法检查的原因**

常见原因有: 文件超过 8 TiB, 文件在读取时被其他应用改动, 或文件管理器授予的读取权限已失效. 错误提示会说明具体原因, 点按 "重试" 可再次检查.
