# 文件检查器

文件检查器通过一次流式读取检查文件. 它会计算 CRC32, MD5, SHA-1, SHA-256 和 SHA-512 校验和, 识别常见文件签名, 并报告基本元数据.

MD5 和 SHA-1 会标记为旧版算法. 粘贴预期校验和即可进行校验. 还可以复制单个校验和, 或复制并分享完整检查报告.

插件需要 AutoJs6 build 5268+. 它完全基于 JVM 实现, 与设备 ABI 无关.

安全和隐私限制:

- 拒绝超过 8 TiB 的文件.
- 文件内容仅打开一次, 并以只读模式顺序处理.
- 仅将前 64 字节作为文件头进行检查.
- 插件不访问网络, 也不请求存储权限.
