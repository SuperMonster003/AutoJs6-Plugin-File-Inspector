# 파일 검사기

파일 검사기는 한 번의 스트리밍 읽기로 파일을 검사합니다. CRC32, MD5, SHA-1, SHA-256, SHA-512 체크섬을 계산하고, 일반적인 파일 시그니처를 식별하며, 기본 메타데이터를 보고합니다.

MD5와 SHA-1은 레거시 알고리즘으로 표시됩니다. 예상 체크섬을 붙여넣어 검증할 수 있습니다. 개별 체크섬을 복사하거나, 전체 검사 보고서를 복사하고 공유할 수도 있습니다.

호스트 빌드 5268 이상이 필요합니다.

안전 및 개인정보 제한:

- 8 TiB보다 큰 파일은 거부됩니다.
- 파일 내용은 한 번만 열리며 읽기 전용 모드에서 순차적으로 처리됩니다.
- 처음 64바이트만 파일 헤더로 검사됩니다.
- 플러그인은 네트워크에 접근하지 않으며 저장소 권한을 요청하지 않습니다.
